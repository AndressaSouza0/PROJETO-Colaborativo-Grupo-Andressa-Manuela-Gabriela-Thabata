Conectar WhatsApp

Escaneie o QR Code abaixo com o WhatsApp do celular para ativar o envio de mensagens.

Carregando QR Code...

Como conectar:

  1. Abra o WhatsApp no celular.
  2. Toque nos três pontos (⋮) e vá em Dispositivos conectados.
  3. Toque em Conectar um dispositivo.
  4. Aponte a câmera para o QR Code ao lado.
  5. Aguarde a confirmação na tela.

Servidor WhatsApp Local

Como iniciar o servidor para conectar o WhatsApp.

Como funciona?

Clique em "Iniciar Servidor" no cabeçalho. O servidor será iniciado e a página redirecionada automaticamente.

Primeira vez?

Execute iniciar.bat na pasta servidor-whatsapp uma única vez para registrar o sistema. Depois disso, o botão do navegador funciona.

Servidor rodando em
Endereço automático — não é necessário configurar nada.
Clique em "Testar Conexão" para verificar o servidor.
