Conectar WhatsApp

Escaneie o QR Code abaixo com o WhatsApp do celular para ativar o envio de mensagens.

Carregando QR Code...

Como conectar:

  1. Abra o WhatsApp no celular.
  2. Toque nos três pontos (⋮) e vá em Dispositivos conectados.
  3. Toque em Conectar um dispositivo.
  4. Aponte a câmera para o QR Code ao lado.
  5. Aguarde a confirmação na tela.

Configurações da Evolution API

Preencha com os dados do servidor WhatsApp gratuito.

Como conseguir esses dados gratuitamente?

Crie uma conta em railway.app, faça o deploy da Evolution API (é gratuito) e copie a URL gerada. O nome da instância e a chave você define durante a configuração. O guia oficial está em evolution-api.com.

URL do Servidor (Evolution API)
Endereço onde sua Evolution API está hospedada.
Nome da Instância
Nome que você deu para a instância na Evolution API. É como se fosse o "apelido" do seu WhatsApp no servidor.
Chave da API (apikey)
Chave de autenticação definida durante a configuração do servidor. Funciona como uma senha para proteger sua API.
